# Grok 17 (Glock 17) 製造マスターマニュアル

本書は、Minecraft 銃撃戦エコシステム（**Gun-Craft**）において、**Grok 17（Glock 17）** を一から自作するために必要なすべての部品リスト、対応する製造機械、およびサプライチェーンの全手順を記した公式ドキュメントです。

---

## 🏭 製造サプライチェーンの全体像

Grok 17 の完成には、**150個以上の個別部品**および**各種精密ネジ**が必要です。これらはすべて、対応する専用のワークステーション（機械）で原材料を加工して製造します。

```text
[原材料: 鉄塊 / 鋼線 / ポリマー / 真鍮]
       │
       ├─► [スプリング巻き機] ──► スプリング・バネ類 (#3, #4, #9 等)
       ├─► [CNC精密加工機]   ──► スライド、トリガー、ピン、精密ネジ (#1, #6, #7, #28~50 等)
       ├─► [射出成形機]       ──► 強化ポリマーフレーム (#5)
       ├─► [ハンマー鍛造機]   ──► マッチグレードバレル (#2)
       │
       └─► [銃器プリント台]   ──► 設計図（プリント済みの紙）
              │
              ▼
    [銃器組立台 (150パーツ + 設計図 + 精密ドライバー)] ──► Grok 17 本体完成！
```

## 🛠️ 組み立て時の注意事項 (重要)

1. **工具の選択**: ネジ（#28〜#50）を締結する際は、必ず対応するミリサイズの**精密ドライバー**をサブハンド（オフハンド）に装備してください。サイズが不適合の場合、**ネジ山が潰れて「故障（Stripped Screw）」**になり、パーツが使用不可能になります。
2. **部品検査**: 組み立てを行う前に、各パーツの状態が「正常 (Normal)」であるかを確認してください。「故障/破損」状態のパーツが1つでも混ざっていると、組立台での最終合体が拒否されます。
3. **設計図の用意**: 組立には、プリント台で作成した **Grok 17 の設計図（プリント済みの紙）** が1枚必要です。
