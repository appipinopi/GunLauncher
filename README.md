# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## 🔩 精密ネジ規格とドライバー工具システム (Gun-Craft)

グロックなどの実銃製造を極限までリアリスティックに再現するため、**ネジのサイズ（mm）**、**専用の精密ドライバー工具**、および**ネジ山の摩耗（Stripped Screw）**に関するハードコアなシステムを導入しました。

### 1. ネジのサイズ規格 (0.5mm 〜 2.0mm+)
- 銃の各部を固定するため、さまざまなミリ単位の「精密ネジ」が存在します。
- **コマンド**: `/guncraft screw <sizeMm>` (例: `/guncraft screw 1.2`)

### 2. 対応ドライバー工具と「ネジ山潰れ」の概念
- 各ネジには適合するドライバーのサイズ範囲（例: 1.0mm 〜 1.5mm対応）があります。
- **不適合な工具**を使用してネジを締めようとすると、一定確率で**ネジ山が潰れ（Stripped Screw / 破損）**、専用の修正工具やパーツ交換が必要になります。
- **コマンド**: `/guncraft driver <minMm> <maxMm>` (例: `/guncraft driver 1.0 1.5`)

### 3. 150+ パーツの細分化
- スライド、バレル、ピン、スプリング、各種マイクロビスを含む**150種類以上の個別部品**が定義されており、それぞれ固有の名称とテクスチャ（CustomModelData）に対応しています。
- **コマンド**: `/guncraft part <1-150>`

## 📦 プラグイン構成（全4種）
1. **Gun-Main**: 必須コアエンジン（Glock 17 標準内蔵）
2. **Gun-Module**: アタッチメント・カスタムパーツ管理
3. **Gun-Craft**: 高度なワークステーション、150+個別部品、工具・ネジ規格システム
4. **Gun-Addon**: ユーザー独自の個人改造・カスタム武器追加用テンプレート
