# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## 🏭 Glock Gen5 製造サプライチェーンと専用機械

Grok 17 (Glock Gen5) を製造するには、Sportec社の公式パーツリスト（Pos. 1 〜 34）に基づき、**全7種の専用ワークステーション**を稼働させてすべての部品を製造・調達する必要があります。

### 📋 ワークステーション一覧と製造担当パーツ

| 機械名称 (ブロック) | クラフト方法 | 担当する公式パーツ (Pos. Nr.) |
| :--- | :--- | :--- |
| **1. 銃器プリント台** (`CARTOGRAPHY_TABLE`) | 鉄インゴット + 地図製図台 | 設計図（Grok 17 Blueprint）の発行 |
| **2. 丸める機械** (`DISPENSER`) | 鉄インゴット + ディスペンサー + 高炉 | 真鍮と鉛球から 9mm 弾薬の成形 |
| **3. 銃器組立台** (`SMITHING_TABLE`) | ネザライト + 金床 + 鍛冶台 | 設計図 + 公式パーツ全34点の最終組み立て |
| **4. スプリング巻き機** (`PISTON`) | 鉄バー + ピストン等 | Pos. 3, 6, 9, 12, 18, 20, 32 (スプリング・バネ類) |
| **5. CNC精密加工機** (`STONECUTTER`) | 鉄インゴット + 石切台 | Pos. 1, 4, 5, 8, 10, 11, 13-15, 19, 21-30, 33-34 (スライド、トリガー、ピン等) |
| **6. 射出成形機** (`FURNACE`) | 炉 + コンクリート等 | Pos. 16, 17 (ポリマーフレーム、ビーバーテイル) |
| **7. ハンマー鍛造機** (`ANVIL`) | 金床 + 鉄ブロック等 | Pos. 2 (Barrel G17 Gen5 / M バレル鍛造) |

### 🛠️ 最終組み立ての条件
銃器組立台（`SMITHING_TABLE`）を右クリックして専用GUIを開き、インベントリ内に **Grok 17 の設計図** と **公式パーツ Pos.1 〜 34 のすべて** を揃えた状態で出力スロットをクリックすることで、最高精度の **Glock Gen5 本体** が完成します！
