# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## 🧩 Glock 17: 100個の個別部品とテクスチャ（CustomModelData）対応

グロックの製造プロセスでは、100個のすべてのパーツが実銃の構造に基づいた個別名称と、リソースパックでテクスチャを変更するための専用 `CustomModelData` を持っています。

### 🏷️ 主要パーツの CustomModelData マッピング例
プレイヤーは `/guncraft part <1-100>` コマンドを使用して、特定の部品を手に入れることができます。

| 部品ID | 名称 | CustomModelData (正常時) | CustomModelData (故障時) |
| :--- | :--- | :--- | :--- |
| `#1` | スライド (Slide) | `5001` | `6001` |
| `#2` | バレル (Barrel) | `5002` | `6002` |
| `#3` | リコイルプロングロッド | `5003` | `6003` |
| `#4` | リコイルスプリング | `5004` | `6004` |
| `#5` | ポリマーフレーム | `5005` | `6005` |
| `#6` | トリガー (Trigger) | `5006` | `6006` |
| `#7` | トリガーバー | `5007` | `6007` |
| `#8` | コネクター | `5008` | `6008` |
| `#9` | トリガーバネ | `5009` | `6009` |
| `#10` | トリガーピン | `5010` | `6010` |
| `#11〜#100` | 各種内部精密メカニカル部品 | `5011` 〜 `5100` | `6011` 〜 `6100` |

### 🎨 リソースパック連携のポイント
リソースパック側で `iron_nugget`（または `barrier`）に対して `custom_model_data` 述語を設定することで、100個すべての部品に個別の3Dモデルやテクスチャを割り当てることが可能です。

## 📦 プラグイン構成（全4種）
1. **Gun-Main**: 必須コアエンジン（Glock 17 標準内蔵）
2. **Gun-Module**: アタッチメント管理
3. **Gun-Craft**: 高度なワークステーション・個別100部品製造システム
4. **Gun-Addon**: ユーザー独自の個人改造・カスタム武器追加用テンプレート
