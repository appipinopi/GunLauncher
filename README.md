# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## ⚙️ Gun-Craft: 実銃の製造工程に基づく高度ワークステーション

実銃の製造プロセス（グロックなどの構造）にインスパイアされ、スプリング、トリガー、バレル、フレームなどをそれぞれ専用の機械で製造する極めてリアルなシステムを導入しています。

### 🏭 新しく追加された専用機械（ワークステーション）
| 機械名称 | コマンド / 用途 | 製造される部品 |
| :--- | :--- | :--- |
| **スプリング巻き機** | `/guncraft spring` | 鋼線からスプリング（ばね類）を成形 |
| **CNC精密加工機** | `/guncraft cnc` | 金属塊からスライドやトリガー等の金属削り出しパーツ |
| **射出成形機** | `/guncraft mold` | ポリマーを高圧で流し込み、銃のフレームを成形 |
| **ハンマー鍛造機** | `/guncraft forge` | 高精度な銃身（バレル）を鍛造 |

### 🛠️ 故障部品（Damaged Parts）の管理
製造工程や使用状況によっては、パーツが破損して**「故障部品（Damaged Part）」**になることがあります。
- 各部品は個別に番号や種類が管理されており、GUI上でどれが正常でどれが故障しているかが一目で分かるようになっています。
- 100個の正常なパーツと設計図を揃えて初めて、組立台（`/guncraft assemble`）で **Glock 17 本体** を完成させることができます。

## 📦 プラグイン構成（全4種）
1. **Gun-Main**: 必須コア。Glock 17 等を標準内蔵。
2. **Gun-Module**: アタッチメント・カスタムパーツ管理。
3. **Gun-Craft**: 高度なワークステーションと100部品・個別パーツ製造システム。
4. **Gun-Addon**: ユーザー独自の個人改造・カスタム武器追加用テンプレート。
