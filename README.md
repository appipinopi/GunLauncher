# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## ⚙️ Gun-Craft: 高度な製造とワークステーションシステム

**Gun-Craft** では、機械のクラフトから個別部品の管理、故障部品の検知まで、リアリティを極限まで高めた製造プロセスを導入しています。

### 1. ワークステーション（機械）のクラフト
銃を製造するには、まず専用の機械をバニラの作業台でクラフトする必要があります。
- **銃器プリント台 (Printing Table)**: `CARTOGRAPHY_TABLE` 周囲を鉄インゴットで囲んでクラフト。
- **丸める機械 (Rolling Machine)**: ディスペンサー、高炉、鉄インゴットでクラフト。
- **銃器組立台 (Assembly Table)**: 金床、鍛冶台、ネザライトインゴットでクラフト。

### 2. 個別部品と「故障部品 (Damaged Parts)」
- 銃の本体を組み立てるには、**100個の精密パーツ**が必要です。
- 製造過程や使用状況によって、パーツが**故障（Damaged）**することがあります。
- どのパーツが破損しているかはアイテムのLore（説明文）と固有のIDで一目で判別でき、修理または交換を行わないと最終的な銃器を組み立てることができません。

### 3. 弾薬と銃器の製造ライン
- **プリント台**: 紙1枚 + イカ墨4個から「設計図」を作成。
- **丸める機械**: 真鍮と鉛球を加工して実包を作成。
- **組立台**: 設計図と100個の正常なパーツを揃えて、初めて銃器本体が完成。
