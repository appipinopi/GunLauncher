# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## 🏭 製造機械コンプリートカタログ（完全必須システム）

すべての銃器、弾薬、個別部品の製造には、**専用のワークステーション（機械ブロック）の設置と物理的な操作（右クリック）が必須**です。コマンドによる簡易生成はできず、工場を建設してサプライチェーンを構築する必要があります。

### 📋 ワークステーション一覧リスト

| 番号 | 機械名称 (ブロック) | クラフト方法 | 主な役割・機能 | 入出力の概要 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **銃器プリント台** (`CARTOGRAPHY_TABLE`) | 鉄インゴット + 地図製図台 | 銃の設計図（型紙）を発行する。 | 紙 + イカ墨 ➔ Glock 17 等の設計図 |
| **2** | **丸める機械** (`DISPENSER`) | 鉄インゴット + ディスペンサー + 高炉 | 薬莢と弾頭を組み合わせて実包（弾薬）を成形する。 | 真鍮 + 鉛球 ➔ 9mm等の弾薬 |
| **3** | **銃器組立台** (`SMITHING_TABLE`) | ネザライト + 金床 + 鍛冶台 | 100個以上の個別パーツと設計図を最終組み立てする。 | 100部品 + 設計図 ➔ Glock 17 本体 |
| **4** | **スプリング巻き機** (`PISTON`) | 鉄バー + ピストン等 | 鋼線からテンションスプリングやバネ部品を巻く。 | 鉄・鋼線 ➔ スプリング部品 (#3, #4等) |
| **5** | **CNC精密加工機** (`STONECUTTER`) | 鉄インゴット + 石切台 | 金属塊からスライドやトリガー等の金属パーツを削り出す。 | 鉄塊 ➔ スライド・トリガー部品 |
| **6** | **射出成形機** (`FURNACE`) | 炉 + コンクリート等 | 高温高圧でポリマーを流し込み、フレームを成形する。 | ポリマー素材 ➔ 強化フレーム部品 |
| **7** | **ハンマー鍛造機** (`ANVIL`) | 金床 + 鉄ブロック等 | 高精度な鋼管を鍛造し、ライフリングの刻まれたバレルを作る。 | 鋼材 ➔ バレル（銃身）部品 |

---

## 🔩 メンテナンスと部品管理
- **150+ 個別パーツ**: すべてのパーツは固有の名称とテクスチャ（CustomModelData）を持ちます。
- **ネジと工具**: ミリ単位（0.5mm〜2.0mm）の精密ネジと適合ドライバーを使用。不適合な工具を使うと**ネジ山が潰れ（Stripped Screw）**、修理が必要になります。
- **📖 製造マスターマニュアル**: 150個すべてのパーツの製造方法や対応機械の詳細は [Grok17.md](docs/Grok17.md) をご参照ください。
