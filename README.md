# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

このリポジトリは、Minecraft（Spigot / Paper 1.21）向けの**4つの独立したプラグインからなる銃撃戦エコシステム**です。

---

## 🛠️ Gun-Craft: 製造と「かたどり」システム

**Gun-Craft** プラグインは、サバイバルモードにおいて現実的な銃器・弾薬製造プロセスを再現します。

### 1. 弾薬製造ライン (Rolling Machine)
- **素材**: 硫黄（火薬）、真鍮（Brass）、鉛（Lead）を使用。
- **丸める機械 (`/guncraft roll`)**: 真鍮の薬莢と鉛球を組み合わせ、専用の機械で成形することで実包を作り上げます。

### 2. 銃器製造ライン (Printing & Assembly)
銃の本体を製作するには、高度な設計図と膨大な部品が必要となります。

- **① プリント台 (`/guncraft print`)**
  - タブやメニューから欲しい銃を選択。
  - **コスト**: 紙 1枚 + イカ墨 4個 ＝ **「プリント済みの設計図」** 1枚。
- **② 銃器組立台 (`/guncraft assemble`)**
  - **重要要件**: 銃の内部機構やパーツは100以上の部品で構成されているため、組み立てには**最低100枚のプリント済み設計図**が必須となります。
  - 100枚の設計図を消費して、初めて本格的な銃の本体が完成します。

## 📦 プラグイン構成一覧

| プラグイン名 | 役割 | コマンド / 特徴 |
| :--- | :--- | :--- |
| **Gun-Main** | コア・公式パッチ | 必須基盤。動的モジュールローダー内蔵。 |
| **Gun-Module** | カスタムパーツ | スコープ、サプレッサー等のアタッチメント管理。 |
| **Gun-Craft** | 製造・かたどり | `/guncraft print`, `roll`, `assemble` による本格クラフト。 |
| **Gun-Addon** | 個人拡張・改造 | ユーザー独自のカスタム武器を追加するテンプレート。 |
