# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

このリポジトリは、Minecraft（Spigot / Paper 1.21）向けの**4つの独立したプラグインからなる銃撃戦エコシステム**です。
各プラグインが専門の役割を持ち、相互に連携することで、公式アップデートから個人の改造までを柔軟にサポートします。

---

## 📦 4つの主要プラグイン構成

| プラグイン名 | 役割 | 詳細 |
| :--- | :--- | :--- |
| **Gun-Main** | **コア・公式パッチ** | **必須プラグイン**。銃の基盤エンジンと公式パッチを提供します。 |
| **Gun-Module** | **カスタムパーツ** | アタッチメント（スコープ、バレル等）やタクティカルアイテムを管理します。 |
| **Gun-Craft** | **製造システム** | 設計図（型紙）から銃をクラフト・製造するためのシステムです。 |
| **Gun-Addon** | **個人拡張・改造** | ユーザーが独自の銃を追加したり、Mainをベースに改造するための入り口です。 |

---

## 🛠️ 各プラグインの機能詳細

### 1. Gun-Main (Core Engine)
銃の登録システム（`GunRegistry`）と、共通のインターフェース（`CustomGun`）を提供します。
- `plugins/Gun-Main/modules/` フォルダにJARを置くことで、公式パッチやモジュールを動的に読み込む機能（Deep形式）を搭載しています。

### 2. Gun-Module (Tactical Parts)
銃の性能を変化させるアタッチメントを提供します。
- **スロット対応**: `SCOPE`, `BARREL`, `MAGAZINE`, `STOCK`
- サンプルとして「4倍スコープ」などが標準搭載されています。

### 3. Gun-Craft (Manufacturing)
銃を「かたどり」から作成するためのシステムです。
- コマンド: `/guncraft blueprint <gunId>`
- 銃の設計図を発行し、プレイヤーが実際に製造できるプロセスを管理します。

### 4. Gun-Addon (Modification)
個人が独自の武器セットを追加したり、既存のロジックを上書きするためのプラグインです。
- サンプルとして `addon:custom_rifle` が実装されており、開発の雛形として利用できます。

## 🚀 導入とビルド方法

1.  リポジトリをクローンします。
2.  ルートディレクトリで `mvn clean package` を実行します。
3.  `target/` フォルダ（各サブモジュール内）に生成された各 `.jar` ファイルをサーバーの `plugins/` フォルダに導入してください。

**注意**: すべてのプラグインを正常に動作させるには、**Gun-Main** が最初にロードされている必要があります。
