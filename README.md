# Gun Plugin Ecosystem (Main, Module, Craft, Addon)

Minecraft（Spigot / Paper 1.21）向けの本格的な銃撃戦エコシステム。

---

## 🔫 Glock 17 を中心とした本格製造プロセス

ユーザー様のご要望に基づき、第一弾として構造が分かりやすく人気の高い **Glock 17（グロック）** の製造ラインを標準実装しました！

### 1. ワークステーションの作成
バニラの作業台で以下の専用機械をクラフトします：
- **銃器プリント台 (Printing Table)**: 設計図の作成
- **丸める機械 (Rolling Machine)**: 真鍮と鉛から9mm弾等の弾薬を成形
- **銃器組立台 (Assembly Table)**: 100個の精密部品と設計図から銃を組み立て

### 2. Glock 17 の製造ステップ
1. **設計図のプリント**: プリント台（`/guncraft print`）で紙1枚とイカ墨4個を使い、**Glock 17 の設計図**を作成。
2. **部品の収集と検査**: 銃の機構を再現するため、組立には**最低100個の正常なパーツ**が必要です。製造過程で「破損した部品（Damaged Part）」が混ざる場合があり、組立台で詳細な状態をチェック・検査します。
3. **最終組み立て**: 100個の正常なパーツと設計図を組立台（`/guncraft assemble`）に投入し、**Glock 17 本体**が完成！

## 📦 プラグイン構成（全4種）
- **Gun-Main**: 必須のコアエンジン。Glock 17 や各種有名銃を標準内蔵。
- **Gun-Module**: スコープなどのカスタムパーツ管理。
- **Gun-Craft**: 高度な製造、ワークステーション、100部品組立システム。
- **Gun-Addon**: ユーザー独自の個人改造・カスタム武器追加用テンプレート。
